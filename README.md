# RoadSoS AI

National Road Safety Hackathon 2026

## Problem
Delay in emergency response after road accidents.

## Solution
RoadSoS AI is a GPS-enabled emergency rescue platform that helps users locate nearby hospitals, police stations, emergency contacts, and activate SOS services.

## Features
- Real-time GPS tracking
- Hospital finder
- Police station locator
- Emergency numbers
- Hospital readiness system
- Family alerts
- Voice assistant
- Roadside emergency pods
- Drone rescue simulation

## Technology Stack
- React
- TypeScript
- Tailwind CSS
- Leaflet Maps
- OpenStreetMap
