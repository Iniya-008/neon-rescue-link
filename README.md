# 🚑 RoadSoS AI – Smart Emergency Rescue Network

## National Road Safety Hackathon 2026

### 📌 Overview

RoadSoS AI is an intelligent emergency response platform designed to reduce response time during road accidents. The system uses real-time GPS location tracking to help users quickly locate nearby hospitals, police stations, and emergency services while providing immediate access to critical emergency resources.

The project aims to improve accident response efficiency and increase the chances of survival during the golden hour after a road accident.

---

## 🎯 Problem Statement

Road accident victims often face challenges such as:

* Delay in locating nearby hospitals
* Slow emergency response
* Difficulty sharing exact accident locations
* Lack of coordination between emergency stakeholders
* Limited access to emergency contact information

These delays can significantly impact survival rates during emergencies.

---

## 💡 Proposed Solution

RoadSoS AI provides a centralized emergency assistance platform that:

* Detects the user's real-time GPS location
* Displays nearby hospitals and trauma centers
* Locates nearby police stations
* Provides quick access to emergency contact numbers
* Enables one-touch SOS activation
* Supports hospital readiness notifications
* Improves emergency response coordination

## 🔄 System Workflow

1. User opens RoadSoS AI.
2. GPS location is detected automatically.
3. Nearby hospitals and police stations are identified.
4. Emergency contacts become instantly available.
5. User activates SOS if required.
6. Emergency response process is initiated.
7. Hospital receives notification and prepares for arrival.

---

## 🌟 Innovation

The Hospital Readiness System differentiates RoadSoS AI from conventional navigation platforms by enabling hospitals to prepare emergency resources before the patient arrives.

This reduces delays during critical treatment periods and improves emergency care effectiveness.

## 💻 How to Run the Project Locally

### Prerequisites

Make sure the following software is installed:

* Node.js (version 18 or later)
* npm (comes with Node.js)

Download Node.js:
https://nodejs.org

---

### Installation Steps

#### 1. Clone the Repository

```bash
git clone https://github.com/Iniya-008/neon-rescue-link.git
```

#### 2. Open the Project Folder

```bash
cd neon-rescue-link
```

#### 3. Install Dependencies

```bash
npm install
```

#### 4. Start the Development Server

```bash
npm run dev
```

#### 5. Open the Website

After the server starts, open the URL displayed in the terminal.

Example:

```text
http://localhost:5173
```

The RoadSoS AI website should now be running locally.

---

### Build for Production

```bash
npm run build
```

---

### Preview Production Build

```bash
npm run preview
```
